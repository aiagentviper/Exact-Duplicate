---
name: Local stock imagery
description: Blog imagery should be stored locally and verified before being wired into the site.
---

Use local, verified stock-image files for repeated editorial card imagery instead of relying on remote or dynamically generated image URLs.

**Why:** Public image search availability and individual remote URLs can be inconsistent, while local assets keep the preview and production build reliable.

**How to apply:** When adding many article thumbnails, download and validate the selected images first, then map each article to a distinct local asset.
