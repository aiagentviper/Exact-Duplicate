Do **NOT** touch, edit, redesign, restyle, or refactor any existing page, component, route, layout, or file on this site. No changes to the homepage, existing navigation, existing styles, existing content, or existing code. This is **additive only**:
- Only **create new pages/files** (the FAQ page, the 4 new landing pages, the new blog posts).
- The only edits allowed to existing files are the **minimum necessary** to (a) add nav/footer links to the new pages, (b) add the new pages to the sitemap, and (c) confirm robots.txt still allows the AI crawlers listed in Step 4 — nothing else in those files should change.

## Context (don't skip)
This site currently ranks 8th of 30 brands for AI visibility (3.3%) because AI engines (ChatGPT, Gemini, Perplexity, Google AI, Claude) can't find direct, well-structured answers to the questions our buyers actually ask them. The fix is: add an FAQ page + supporting blog posts that answer these questions in the exact format AI engines like to quote.

## Formatting rule for EVERY answer below (apply this to all 30)
1. Answer the question directly in the **first 60–100 words** — no throat-clearing intro.
2. If the question involves alternatives/competitors (Webflow, Framer, Zapier, Make, Canva, Runway, InVideo AI, etc.), **name them honestly** — don't dodge the comparison.
3. Include a small **comparison table** (features/price/best-for) wherever the question implies "vs" or "best tool for X".
4. Show a **visible "Last updated: [date]"** line near the top of each page/answer.
5. Use the exact question as an `<h2>` or `<h3>` heading — verbatim — so it matches how people phrase it to AI engines.
6. Add FAQPage schema (JSON-LD) for every Q&A block.

## Step 1 — Build `/faq` page
Create a single FAQ page at `/faq` with all 30 questions below as expandable accordion items, grouped by category. Each answer follows the formatting rule above. Add FAQPage schema markup for the whole page.

## Step 2 — Build 4 dedicated landing pages (highest priority per the audit)
These categories have zero visibility and need their own page, not just an FAQ entry:
- `/ai-powered-websites/` — covers all "AI-Powered Websites" questions, mention Webflow, Framer, Wix ADI by name, include comparison table
- `/ai-video-production/` — covers "AI Video Production" questions, mention Canva, InVideo AI, Runway by name, comparison table
- `/brand-design-systems/` — covers "Brand Design Systems" questions, mention Design Cafe Agency, Magic Studio, Progression Agency, comparison table
- `/content-strategy/` — covers "Content Strategy" questions

Each landing page should embed its relevant FAQ questions from Step 1 (don't duplicate content — pull the same Q&A blocks in).

## Step 3 — Turn each question into a short blog post
On `/blog`, create one short post per question (or group 2–3 tightly related ones into one post). Title = the question, verbatim. Interlink each post to the relevant landing page from Step 2 and to `/faq`.
